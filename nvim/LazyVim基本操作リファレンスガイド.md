# LazyVim 基本操作リファレンスガイド

## 1. 概要
本資料では、LazyVim環境における標準的なキーバインドと操作方法について解説します。LazyVimは Neovim をベースとしており、`<Leader>` キー（デフォルトは `Space`）を起点とした操作が中心となります。

## 2. 前提条件
* Neovim (v0.9.0以降推奨) がインストールされていること
* LazyVim がセットアップ済みであること
* ターミナルフォントに Nerd Fonts が設定されていること（アイコン表示のため）

## 3. 基本操作

### 3.1 ファイルツリー (neo-tree)
ファイルのブラウズや管理に使用します。

| 操作 | キーバインド | 説明 |
| :--- | :--- | :--- |
| ツリーの開閉 | `<Leader> e` | 左側にエクスプローラを表示/非表示にします。 |
| ツリーへのフォーカス | `<Leader> fe` | エクスプローラを開き、現在のファイルを選択した状態にします。 |

**エクスプローラ内での操作:**
* `a`: ファイル/ディレクトリの新規作成
* `d`: 削除
* `r`: 名前変更
* `y`: パスのコピー
* `H`: 隠しファイルの表示切替

### 3.2 カーソル移動・ウィンドウ操作
効率的な画面遷移のための操作です。

| 操作 | キーバインド | 説明 |
| :--- | :--- | :--- |
| ウィンドウ移動 | `Ctrl + h/j/k/l` | 左/下/上/右のウィンドウへ移動します。 |
| ウィンドウ分割 (垂直) | `<Leader> w |` | 画面を左右に分割します。 |
| ウィンドウ分割 (水平) | `<Leader> w -` | 画面を上下に分割します。 |
| タブ(Buffer)切り替え | `[ b` / `] b` | 前/次のバッファ（開いているファイル）へ移動します。 |
| バッファを閉じる | `<Leader> bd` | 現在のバッファを閉じます。 |

### 3.3 ファイル検索・テキスト検索 (Telescope)
プロジェクト内のリソースを高速に検索します。

```bash
# ファイル名で検索
<Leader> <Space>

# プロジェクト内全文検索 (grep)
<Leader> sg

# 最近開いたファイル履歴
<Leader> fr

# キーマップの確認
<Leader> sk
```

## 4. 編集補助・LSP操作
コードの構造を理解し、素早く編集するための機能です。

| 操作 | キーバインド | 説明 |
| :--- | :--- | :--- |
| 定義ジャンプ | `gd` | カーソル下のシンボルの定義場所へ移動します。 |
| 参照確認 | `gr` | そのシンボルが使われている箇所を一覧表示します。 |
| コードアクション | `<Leader> ca` | 修正提案やリファクタリングメニューを表示します。 |
| シンボル名変更 | `<Leader> cr` | 変数名などの一括リネームを実行します。 |
| フォーマット | `<Leader> cf` | コードの整形を実行します。 |
