# LinuC 102 1.05：シェル、スクリプト、およびデータ管理

■1. シェルの環境設定

### export
```bash
# 環境変数を設定、またはエクスポートする
# export {変数名}={値}
export LANG=ja_JP.UTF-8
# (備考) 現在のシェルから起動される子プロセスにも変数を引き継ぐ
```

### alias
```bash
# コマンドの別名（エイリアス）を設定する
# alias {別名}='{元のコマンド}'
alias ll='ls -l'
# (備考) 引数なしで実行すると現在設定されているエイリアス一覧を表示
```

### env
```bash
# 環境変数を一覧表示する、または変数を指定してコマンドを実行する
# env
env | grep PATH
# (備考) setコマンドとの違い（envは環境変数のみ）が試験で問われる
```


■2. シェルスクリプトの基本操作

### source (.)
```bash
# スクリプトファイルを現在のシェル環境で実行する
# source {ファイルパス}  または  . {ファイルパス}
source ~/.bashrc
# (備考) 新しいシェルを起動せずに実行するため、変数の変更が即座に反映される
```

### read
```bash
# 標準入力から1行読み込んで変数に代入する
# read {変数名}
read USER_INPUT
# (備考) シェルスクリプト内でユーザーとの対話を作る際によく使われる
```


■3. データベース管理（SQLの基本）

### mysql
```bash
# MariaDB/MySQL クライアントを起動する
# mysql -u {ユーザー名} -p {データベース名}
mysql -u root -p
# (備考) 102試験では基本的なSQL文（SELECT, INSERT, UPDATE, DELETE）も範囲内
```

### psql
```bash
# PostgreSQL クライアントを起動する
# psql -U {ユーザー名} {データベース名}
psql -U postgres mydb
# (備考) PostgreSQL固有のメタコマンド（\d, \qなど）も重要
```
