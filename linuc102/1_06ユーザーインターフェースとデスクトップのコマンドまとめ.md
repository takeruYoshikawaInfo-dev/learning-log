# LinuC 102 1.06：ユーザーインターフェースとデスクトップ

■1. X Window System の管理

### startx
```bash
# X Window Systemを起動する
# startx [オプション]
startx
# (備考) 個別のユーザー設定（~/.xinitrc）に基づいてGUI環境を開始する
```

### xhost
```bash
# Xサーバへのアクセス権限をホスト単位で制御する
# xhost [+/-]{ホスト名}
xhost +192.168.1.10
# (備考) "+"は許可、"-"は拒否。セキュリティ上、現在はssh -Xなどが推奨される
```

### xauth
```bash
# Xサーバの認証情報（MIT-MAGIC-COOKIE-1）を表示・編集する
# xauth [コマンド]
xauth list
# (備考) ユーザーごとの認証ファイルを管理する
```


■2. ディスプレイマネージャとアクセシビリティ

### xwininfo
```bash
# 表示されているウィンドウの詳細情報を表示する
# xwininfo
xwininfo
# (備考) 実行後に特定のウィンドウをクリックすると、IDやサイズが表示される
```

### DISPLAY (環境変数)
```bash
# Xクライアントが接続する先のディスプレイを指定する
# export DISPLAY={ホスト名}:{ディスプレイ番号}.{スクリーン番号}
export DISPLAY=:0.0
# (備考) ローカルの最初のディスプレイを指す設定
