# LinuC 101 1.01：システムアーキテクチャのコマンドまとめ

## 1. ハードウェア情報の確認

### lsusb
```bash
# USBデバイスの情報を表示する
# lsusb [オプション]
lsusb -v
# (備考) -vは詳細情報を表示
```

### lspci
```bash
# PCIデバイスの情報を表示する
# lspci [オプション]
lspci -k
# (備考) -kは使用中のカーネルドライバも表示
```

### lsmod
```bash
# ロードされているカーネルモジュールの一覧を表示する
# lsmod
lsmod
```

### modprobe
```bash
# カーネルモジュールのロードまたはアンロードを行う
# modprobe [オプション] {モジュール名}
sudo modprobe dummy
# (備考) 依存関係を解決してロードする。-rでアンロード
```


## 2. システムの起動とシャットダウン

### dmesg
```bash
# カーネルのリングバッファ（起動時のログ等）を表示する
# dmesg [オプション]
dmesg | grep -i cpu
# (備考) 起動時のハードウェア認識確認によく使用される
```

### shutdown
```bash
# システムをシャットダウンまたは再起動する
# shutdown [オプション] {時間}
sudo shutdown -h now
# (備考) -hは停止、-rは再起動。nowは即時実行
```

### reboot
```bash
# システムを再起動する
# reboot
sudo reboot
```


## 3. systemd と ランレベル（ターゲット）の管理

### systemctl
```bash
# systemdのユニット（サービスやターゲット）を制御する
# systemctl [サブコマンド] {ユニット名}
systemctl status sshd
# (備考) サービスの起動・停止・状態確認に使用
```

### systemctl get-default
```bash
# 現在のデフォルトのターゲット（旧ランレベル）を表示する
# systemctl get-default
systemctl get-default
# (出力例) multi-user.target
```

### systemctl set-default
```bash
# デフォルトのターゲットを変更する
# systemctl set-default {ターゲット名}
sudo systemctl set-default graphical.target
# (備考) 次回起動時からグラフィカルログイン(旧ランレベル5)になる
```

### systemctl isolate
```bash
# 現在のターゲットを即座に切り替える
# systemctl isolate {ターゲット名}
sudo systemctl isolate reboot.target
# (備考) 即座に再起動を実行する
```
