# LinuC 101 1.04：デバイス、Linuxファイルシステム、FHS

■1. パーティション管理

### fdisk
```bash
# 既存のパーティション構成を表示・操作する
# fdisk [オプション] {デバイス名}
sudo fdisk -l
sudo fdisk /dev/sdb
# (備考) -l は一覧表示。対話モードでパーティションを作成する
```

### parted
```bash
# パーティションの作成・削除・リサイズを行う
# parted {デバイス名}
sudo parted /dev/sdb
# (備考) GPT形式のディスクや2TB以上の大容量ディスクに推奨される
```


■2. ファイルシステムの作成と整合性チェック

### mkfs
```bash
# パーティション上にファイルシステムを作成（フォーマット）する
# mkfs -t {型} {デバイス名}
sudo mkfs -t ext4 /dev/sdb1
# (備考) mkfs.ext4 や mkfs.xfs のように直接実行も可能
```

### fsck
```bash
# ファイルシステムの検査と修復を行う
# fsck [オプション] {デバイス名}
sudo fsck /dev/sdb1
# (備考) 必ずアンマウントした状態で実行すること
```


■3. マウントとディスク使用量の確認

### mount
```bash
# ファイルシステムをディレクトリツリーに接続する
# mount [オプション] {デバイス名} {マウントポイント}
sudo mount /dev/sdb1 /mnt
# (備考) 引数なしで実行すると、現在マウントされている一覧を表示
```

### umount
```bash
# マウントされているファイルシステムを切り離す
# umount {デバイス名 または マウントポイント}
sudo umount /mnt
# (備考) 使用中のファイルがある場合はエラーになる
```

### df
```bash
# ファイルシステムのディスク使用量を表示する
# df [オプション]
df -h
# (備考) -h は人間が読みやすい形式（GB, MBなど）で表示
```

### du
```bash
# ディレクトリ内のファイル容量を表示する
# du [オプション] {ディレクトリパス}
du -sh /var/log
# (備考) -s は合計のみ、-h は単位を付けて表示
```


■4. 所有権と権限（1.03より詳細な管理）

### tune2fs
```bash
# ext2/ext3/ext4ファイルシステムのパラメータを調整する
# tune2fs [オプション] {デバイス名}
sudo tune2fs -l /dev/sda1
# (備考) -l は詳細な設定値（ボリュームラベルやマウント回数など）を表示
```
